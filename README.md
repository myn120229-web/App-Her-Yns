## 💡 توصیه‌های طلایی (از تجربه کارآموزان قبلی Outreachy)

1. **کیفیت مهم‌تر از تعداد است** — ۳ PR خوب با تست و مستندات بهتر از ۱۰ PR سطحی است.
2. **سریع به بازخورد پاسخ بده** — سرعت اصلاح، معیار اعتماد منتورهاست.
3. **قبل از نوشتن کد در issue اعلام حضور کن** — «I'm working on this» تا کار تکراری نشود.
4. **همیشه تست بنویس** — PR بدون تست به‌سختی merge می‌شود.
5. **پایداری مهم است** — حضور روزانه منظم بیش از کارهای انبوه و مقطعی ارزش دارد.
6. **مستندات و مثال‌ها هم مشارکت واقعی‌اند** — راه شروع عالی برای تازه‌واردها.
7. **پیام تشکر بفرست** — منتورهای همین امسال، منتورهای سال بعد هم هستند.
8. **برای دور بعد، زودتر شروع کن** — Initial Application فقط یک هفته باز است (۲۴ تا ۳۱ آگوست / فوریه ۲۰۲۷)؛ هشدار تقویم بگذار.

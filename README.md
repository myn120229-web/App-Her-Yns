# 🌟 Outreachy — پلن ۳۰ روزه آماده‌سازی

## Outreachy چیست؟

**Outreachy** یک برنامه کارآموزی **پولی، ریموت و سه‌ماهه** در دنیای نرم‌افزار آزاد و متن‌باز (FOSS) است که زیرمجموعه‌ای از بنیاد **Software Freedom Conservancy** اداره می‌شود.

### مشخصات اصلی

| ویژگی | توضیح |
|--------|--------|
| 💵 **حقوق** | ۷,۰۰۰ دلار آمریکا (کل دوره، در ۳ پرداخت) |
| 🌍 **محل کار** | کاملاً ریموت از هر جای دنیا |
| 🕰 **مدت** | ۳ ماه (دوره‌های ماه مه تا آگوست یا دسامبر تا مارس) |
| 💼 **کار** | مشارکت واقعی در پروژه‌های متن‌باز مانند Linux، GNOME، Mozilla، scikit-learn |
| 🎓 **مدرک** | نیاز به مدرک تحصیلی ندارد |
| 🛂 **ویزا** | نیاز ندارد — کاملاً ریموت |
| 👥 **هدف** | حمایت از افراد کم‌نماینده (Underrepresented) در فناوری |

### تقویم دو دوره سالانه

**دوره مه (May cycle):**
- ثبت‌نام اولیه: اوایل فوریه
- بازه مشارکت (Contribution Period): ۱۷ مارس تا ۱۵ آوریل
- شروع کارآموزی: ۱۸ مه تا ۱۷ آگوست

**دوره دسامبر (December cycle):**
- ثبت‌نام اولیه: اوایل تا اواسط آگوست
- بازه مشارکت: اواخر سپتامبر تا اواخر اکتبر
- شروع کارآموزی: اوایل دسامبر تا اوایل مارس سال بعد

### فرایند پذیرش دو مرحله‌ای

**مرحله ۱ — ثبت‌نام اولیه (Initial Application):**
پاسخ به سؤالات انگیزشی و اثبات واجد شرایط بودن (بر اساس تجربه تبعیض یا کم‌نمایندگی در صنعت فناوری کشور محل زندگی خود).

**مرحله ۲ — دوره مشارکت (Contribution Period):**
حدود یک ماه مشارکت واقعی و رایگان در یک پروژه انتخابی. متقاضیان بر اساس کیفیت و پایداری مشارکت‌هایشان انتخاب می‌شوند.

### آمار کارآموزان قبلی (خوداظهاری، مطالعه ۲۰۱۹)
- ۹۲٪ زن
- ۴٪ مرد
- ۴٪ ترنس‌جندرت / جندرکوئیر / غیرباینری
- ۶۴٪ رنگین‌پوست
- ۱۲٪ از طبقه یا قبیله‌های به‌حاشیه‌رانه تاریخی

## چرا این پلن ساخته شد؟

این پلن برای یک متقاضی ایرانی طراحی شده که:
- **مهارت‌ها:** Python، FastAPI، Streamlit، Git، GitHub، pandas، NumPy، scikit-learn (الگوریتم‌های کلاسیک ML)
- **هدف:** پذیرش در دوره دسامبر ۲۰۲۶ Outreachy با پروژه‌های مرتبط با ML/Python
- **محدودیت زمانی:** یک ماه دقیق از ۱ تا ۳۰ اکتبر ۲۰۲۶

ساختار پلن بر اساس تجربه‌ی کارآموزان قبلی و توصیه‌های رسمی برنامه تنظیم شده است:

### 📊 توصیه‌های کلیدی کارآموزان قبلی (از وبلاگ‌ها، توییتر، و انجمن‌ها)

1. **زود شروع کن** — مشارکت‌هایی که در ۲-۳ روز اول ارسال شوند، توجه بیشتری می‌گیرند.
2. **کیفیت مهم‌تر از تعداد است** — ۳-۴ PR خوب با تست و مستندات، بهتر از ۱۰ PR کوچک بی‌ارزش.
3. **سریع به بازخورد منتورها پاسخ بده** — سرعت اصلاح، معیار اعتماد منتورهاست.
4. **قبل از نوشتن کد، در issue اعلام حضور کن** — «I'm working on this» تا کار تکراری انجام ندهی.
5. **طراحی را قبل از پیاده‌سازی کامل تأیید بگیر** — بازنویسی کامل، بزرگ‌ترین هدررفت وقت است.
6. **همیشه تست بنویس** — PR بدون تست احتمال مرج شدن بسیار کمی دارد.
7. **به متقاضیان دیگر کمک کن** — فرهنگ جامعه بخشی از ارزیابی است.
8. **پیام تشکر بفرست** — منتورها سال بعد هم همان‌جا هستند.
9. **در Final Application از لینک PRها استفاده کن** — هر ادعا با شواهد پشتیبانی شود.
10. **پایداری مهم است** — حضور روزانه منظم، پیامدهای خوبی در انتخاب دارد.

### 📈 توزیع کار ۳۰ روزه

- **هفته ۱ (روز ۱-۷):** شناخت، راه‌اندازی محیط، اولین PR
- **هفته ۲ (روز ۸-۱۴):** مشارکت در پروژه دوم + شروع feature
- **هفته ۳ (روز ۱۵-۲۱):** پیش‌نویس و ارسال Final Application + PRهای بیشتر
- **هفته ۴ (روز ۲۲-۳۰):** نهایی‌سازی، پیگیری، جمع‌بندی
